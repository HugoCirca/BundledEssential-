# AutoSell

- `/autosell` — help; `/autosell give <player> [amount]` — admin (op)
- Buy chest in Custom $500. Right-click air to set interval 30s/1m/5m/10m + recipients (equal split, offline too). Sneak+right-click placed to reconfigure. Hoppers feed it. Break returns chest (config kept).
- Tune `autosell.*` in `config.yml`.
