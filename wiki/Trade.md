# Trade

- `/trade <player>` — send request
- `/trade accept` / `/tradeaccept` — open 54-slot GUI (left/right offers, glass divider, heads + green/red panes)
- `/trade cancel` / `/tradecancel` — cancel pending or open trade

Requests expire 30s. Changing any offer resets both accepts (anti-scam). Close/quit/cancel refunds. Tab: `accept/cancel` + players.
