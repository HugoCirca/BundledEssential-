# Commands

| Command | Description | Tab |
|---------|-------------|-----|
| `/tpa <p>` `/tpa here <p>` `/tpa accept` `/tpa auto [on|off]` | Teleport requests | players + `here/accept/auto/on/off` |
| `/tpaccept` `/tpahere <p>` `/tpaauto [on|off]` | Legacy aliases | — |
| `/home` `/home set` `/home remove` `/sethome` `/removehome` `/back` | Homes | `set/remove` |
| `/waypoint [new|delete|<name>]` | Waypoints | `new/delete` + names |
| `/trade <p>` `/trade accept` `/trade cancel` | Trade | `accept/cancel` + players |
| `/shop [search <name>]` `/sell` `/sellgui` | Shop/sell | `search` |
| `/balance [p]` `/resetbal <p> [amt]` `/serverbank [history]` `/resetserverbal` | Economy | players + `history/0/1000` |
| `/pay <p> <amt>` `/bounty <p> [amt]` `/paytax` `/repair [full]` | Pay/bounty | players + `<amount>` |
| `/loan [pay [id|all]|info]` | Loans | `pay/info/list` + ids |
| `/craft` (`workbench/wb`) | Portable table | — |
| `/autosell [give <p> [amt]]` | Auto-sell | `give` + players |
| `/giveaway <amt> [count|all|<p>]` | Giveaway | `<amount>/all` + players |
| `/level [p]` `/daily` `/quest [claim|skip]` | Level/quests | players + `claim/skip` |
| `/playtime [leaderboard|top|optin|optout|vault|<p>]` | Playtime | `leaderboard/top/opt…` + players |
| `/waypoint` | Waypoints | — |
| `/bundledhelp` `/be help|version|update` `/bundleversion` `/bundledupdate` `/bundledreload` | Help/update | `help/version/update` + `history` |

All have tab-complete (second arg shows correct subcommands, not just usernames).
